# 📜 Processo de Certificação de Conclusão

## Requisitos para Emissão

Para obter o certificado de especialista em **Engenharia de Software Mobile** ou **Arquitetura de Software Mobile**, o aluno deverá cumprir as seguintes etapas:

1. **Repositório Público do Aluno:** Criar um *fork* ou novo repositório público no GitHub contendo o código de todas as entregas práticas.
2. **Pipelines Aprovadas:** Todos os projetos dos módulos devem possuir a automação do GitHub Actions passando com sucesso no repositório do aluno.
3. **Aprovação do Capstone:** O Projeto Capstone final deve ser avaliado com nota igual ou superior a 8.0/10.0 por um dos mentores responsáveis através de Code Review nas Issues do repositório.

## Como Solicitar seu Certificado

Ao concluir todas as entregas, abra uma **Issue** neste repositório principal com o título:
`[SOLICITAÇÃO DE CERTIFICADO] - Seu Nome Completo`

Inclua no corpo da Issue:
* Link do seu repositório com os projetos finalizados.
* Links dos Pull Requests de cada módulo aprovados.
* Link da avaliação do Projeto Capstone realizada pelo mentor.

A equipe validará os dados e emitirá o certificado em formato digital com link único de verificação e QR Code.
